# MSI Afterburner Monitoring Config

Personal backup of monitoring settings and OSD layout. 
**No overclocking data included.**

### Setup
1. Close **MSI Afterburner** and **RTSS**.
2. Copy `MSIAfterburner.cfg` to:  
   `C:\Program Files (x86)\MSI Afterburner\Profiles`
3. Copy `Global` to:  
   `C:\Program Files (x86)\RivaTuner Statistics Server\Profiles`
4. Restart applications.
